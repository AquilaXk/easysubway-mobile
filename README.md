## 지하에서도. 인터넷 없이도.

역 검색과 길찾기를 기기 안에서 처리합니다. 신호가 끊긴 지하에서도 필요한 정보를 확인할 수 있습니다.

## 당신의 상황이 곧 기준.

휠체어, 유모차, 불편한 걸음. 이동 조건을 고르면 계단을 피하는 경로와 접근성 정보를 먼저 보여줍니다.

## 아는 것과 모르는 것을 구분합니다.

시설 정보에는 출처와 확인 시점을 담고, 확인되지 않은 상태를 확정된 사실처럼 표시하지 않습니다.

## 신고는 가입 없이.

엘리베이터나 편의시설 문제를 발견하면 계정 없이 알릴 수 있습니다. 접수 번호로 처리 상태를 확인합니다.

## 당신을 따라다니지 않습니다.

계정 없음. 추적 없음. 개인정보 판매 없음. 즐겨찾기와 최근 검색은 기기에 저장됩니다.
